# Moon

Website for the *Moon* album by Frank and Agape — track list and lyrics.

Built with [Astro](https://astro.build) and deployed to GitHub Pages at
https://frank-esp73.github.io/Moon-cd-project

## Adding/editing lyrics

Each track is a markdown file in `src/content/tracks/`. Edit the file's body
to add real lyrics, replacing the `*Lyrics coming soon.*` placeholder.

## Development

```
npm install
npm run dev
```

## Deploying

Push to `main` — a GitHub Actions workflow builds the site and publishes it
to GitHub Pages automatically.
